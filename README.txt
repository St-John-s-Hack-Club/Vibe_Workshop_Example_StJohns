BEYOND THE BLUE — Solar System website

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Use the navigation bar to move between the four pages.

FILES
- index.html: Welcome landing page
- planets.html: Interactive planet explorer
- humanity.html: Human and robotic exploration
- outbound.html: Spacecraft sent into and beyond the Solar System
- style.css: Shared responsive design
- script.js: Mobile navigation and planet selector

This is a static website built with HTML, CSS and vanilla JavaScript. No build tools or server are required.
Internet access is required for the optional Google Fonts import and the external source links.
